# Software Stack & Performance — From CUDA to LLM Throughput

The capstone of the NVIDIA GPU Architectures series: walks through CUDA's full software stack — driver, runtime, cuBLAS / cuBLASLt, cuDNN, CUTLASS, Transformer Engine, NCCL, Triton, TensorRT-LLM, vLLM — and finishes with a performance model that turns a GPU spec sheet into LLM tok/s estimates. Includes an interactive end-to-end performance calculator across model size, precision, GPU, batch and sequence length.

**Live site:** https://brendanjameslynskey.github.io/NVIDIA_GPU_10_Software_and_Performance/

Part of the [NVIDIA GPU Architectures series](https://github.com/BrendanJamesLynskey/LLMs#nvidia-gpu-architectures).
